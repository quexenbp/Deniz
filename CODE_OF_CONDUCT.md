# Code of conduct

## Our pledge

We want participation to be harassment-free for everyone, regardless of age,
body size, disability, ethnicity, gender identity, experience, nationality,
personal appearance, race, religion, or technical preference.

## Expected behaviour

- Assume good faith; critique code, not people.
- Keep reviews specific and actionable.
- Accept that "it depends" is a valid answer when trade-offs are real.
- Credit prior work.

## Unacceptable behaviour

- Personal attacks, sustained disruption, or dismissiveness.
- Publishing private information without permission.
- Plagiarism or license violations.

## Enforcement

Report issues to the maintainers via a GitHub issue or the address in
`SECURITY.md`. Maintainers may warn, edit, or remove contributions, and ban
repeat offenders.

This is a short adaptation of the Contributor Covenant, version 2.1.
