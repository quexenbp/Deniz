# Security policy

Report vulnerabilities privately via GitHub Security Advisories:

https://github.com/quexenbp/Deniz/security/advisories/new

Do not open a public issue for a vulnerability before a fix is available.

Include:

- affected version or commit,
- a minimal reproduction,
- the impact (confidentiality / integrity / availability),
- whether a provider key or account is needed.

Deniz is an OSINT client. Findings in third-party data sources (Google, crt.sh,
Cert Spotter, ...) should say so explicitly.
